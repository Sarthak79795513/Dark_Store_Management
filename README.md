# Dark Store Management

A dynamic AI-driven system for managing inventory in dark stores by forecasting demand, monitoring expiry, and offering actionable insights via real-time dashboards and an intelligent chatbot.

---

##  Features
- **Inventory Tracking** – Continuous stock-level monitoring.
- **Expiry Alerts** – Timely reminders for near-expiry products.
- **AI Chatbot** – Conversational assistant for queries and insights.
- **Dashboard Analytics** – Graphical visualizations of demand, sales, and performance.
- **Demand Prediction** – Machine learning models forecasting future demand.
